果冻晃动 · 使用说明

1上传图片

首次打开点击画布中央的「点击上传图片」。之后想换图，点标题栏的 🖼 图标。图片不会上传服务器，全部在本地处理。

2选择果冻

面板「果冻设置」里有 4 个彩色圆点：

  • 果冻 1（正红 / 涂抹红色，光标深红）
  • 果冻 2（浅蓝 / 涂抹浅蓝，光标正蓝）
  • 果冻 3（正黄 / 涂抹正黄，光标正黄）
  • 果冻 4（浅绿 / 涂抹浅绿，光标深绿）

点圆点可以同时显示或隐藏多个果冻行，不是单选。点亮的行代表"当前可在画布上操作这个果冻"。

3涂抹区域

点某个果冻行里的「涂抹」按钮，然后在画布上按住拖动。被涂抹的区域会以该果冻的颜色半透明覆盖，这些区域就是"会晃动的地方"。

笔刷大小、软硬由「共享参数 → 笔刷」控制。

4晃动图片

点「晃动」按钮，在画布上按住拖动，就会在鼠标附近产生推挤和回弹。松手后会像果冻一样晃动。

参数影响手感：

  • 弹性 — 回弹的速度，越大越"紧"
  • 阻尼 — 晃动的持续度，越大越快停下
  • 力度 — 拖拽产生的推力大小

5自动晃动

点「自动晃动」让该果冻持续摆动，不用手动拖。旁边「模式」下拉可以选：

  • 综合 — 每隔「间隔」秒在下面几种里随机切换
  • 左右 / 上下 / 逆时针 / 顺时针 / 左上↘右下 / 左下↗右上

「间隔」控制综合模式的切换周期。「自动速度」「自动幅度」在共享参数里调节。

6晃动光标

开启后，画布上会跟着鼠标或自动轨迹显示一个圆圈，颜色对应果冻，便于看到当前作用范围。

7重置 / 导出

  • 重置（标题栏 ↺ 图标）— 清除所有涂抹和位移，回到初始状态
  • 导出 WebM — 在「导出」抽屉里，可调 5~30 秒，默认 6 秒。点导出后会自动录制并下载 webm 视频文件

8面板折叠

  • 点「果冻设置」「共享参数」「导出」标题可以独立折叠/展开
  • 点右上「收起 ◀」整个面板滑入侧边，画布占满屏幕
  • 面板收起时左上角会出现 ☰ 按钮，点一下重新展开
小技巧：双击任意参数数值可以快速重置到默认值。「间隔」拖动越小自动模式切换越快。导出前先让所有果冻的自动晃动都打开，效果更生动。
