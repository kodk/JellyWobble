# 🍮 JellyWobble · 果冻晃动

一个纯前端的「果冻晃动」整蛊小工具。上传任意图片，涂抹你想晃动的区域，然后拖拽或自动晃动，让静态图片像果冻一样 Q 弹抖动，还可以导出成 WebM 视频。

🔗 **在线体验：** [https://kodk.github.io/JellyWobble/](https://kodk.github.io/JellyWobble/)

---

## ✨ 功能特性

- **上传图片** — 支持常见图片格式，全部在本地处理，不上传服务器。
- **涂抹区域** — 用画笔在图片上涂抹，只有涂过的地方才会变成“果冻”。
- **4 个独立图层** — 红、浅蓝、黄、浅绿四种果冻，可分别涂抹、叠加，互不干扰。
- **手动晃动** — 在画布上按住拖动，像推挤真实果冻一样产生弹动和回弹。
- **自动晃动** — 每个果冻可独立开启自动摆动，支持 6 种运动模式（左右、上下、逆时针、顺时针、两条对角线）以及随机切换的「综合」模式。
- **参数调节** — 弹性、阻尼、笔刷大小、力度、自动速度、自动幅度均可实时调整。
- **晃动光标** — 可显示当前作用范围的光圈，方便定位。
- **导出 WebM** — 录制 5~30 秒的动画并自动下载，直接分享给朋友。
- **响应式布局** — 手机和电脑都能用，面板可折叠，画布自适应。
- **纯本地处理** — 图片不会上传到任何服务器，隐私安全。

## 📖 使用方法

1. **上传图片**
   首次打开点击画布中央的「点击上传图片」，或点击标题栏的 🖼 图标更换图片。

2. **选择果冻图层**
   在「果冻设置」中点击彩色圆点显示/隐藏对应的果冻行。被点亮的行表示当前可以在画布上操作。

3. **涂抹区域**
   选中某个果冻行，点击「涂抹」，然后在画布上按住拖动。被涂抹的区域会以该果冻的颜色半透明覆盖，这些区域就是“会晃动的地方”。

4. **晃动图片**
   - 点击「晃动」，在画布上按住拖动即可推挤果冻。
   - 点击「自动晃动」，让该果冻持续摆动，旁边「模式」下拉可选择摆动方式。
   - 打开「晃动光标」可以看到当前作用范围。

5. **调节参数**
   在「共享参数」抽屉中调整弹性、阻尼、笔刷、力度、自动速度、自动幅度。**双击任意数值可快速重置到默认值。**

6. **重置 / 导出**
   - 标题栏的 ↺ 图标：清除所有涂抹和位移，回到初始状态。
   - 「导出」抽屉：选择时长（5~30 秒），点击「导出 WebM」自动录制并下载。

7. **面板折叠**
   点击「果冻设置」「共享参数」「导出」标题可独立折叠/展开。点右上「收起 ◀」整个面板滑入侧边，画布占满屏幕；点左上角 ☰ 重新展开。

> 💡 **小技巧：** 导出前先打开所有果冻的自动晃动，效果更生动。双击数值快速重置很顺手。

## 🛠️ 技术实现

- **WebGL** — 使用网格顶点 + 片段着色器渲染变形后的图片。
- **弹簧-质点物理** — 每个顶点受邻接约束和锚点约束，配合阻尼模拟果冻弹性。
- **MediaRecorder + captureStream** — 录制画布并导出 WebM 视频。
- **纯原生 JavaScript** — 无任何框架或构建工具，单文件即可运行。

## 💻 本地运行

方式一：直接双击 `index.html` 在浏览器中打开。

方式二：启动一个本地静态服务器（推荐，避免某些浏览器限制）：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js (需要先安装 http-server)
npx http-server -p 8000
```

然后访问 `http://localhost:8000`。

---

## 🌐 浏览器兼容性

- 推荐使用 **Chrome / Edge / Firefox** 最新版。
- **WebGL** 必须开启，否则无法运行。
- **WebM 导出** 依赖 `MediaRecorder` 和 `canvas.captureStream`，Safari 对 WebM 支持有限，可能无法导出。
- 移动端浏览器性能因设备而异，建议使用较新的机型。
